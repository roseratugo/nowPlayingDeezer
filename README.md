# Now Playing Deezer

> **⚠️ Ce projet est archivé.**
>
> Une version entièrement refactorisée a été publiée sous le nom **Orpheus** sur le compte Collectif Pixel.
>
> **Orpheus** fonctionne avec n'importe quelle application musicale sur macOS (Deezer, Spotify, Apple Music, YouTube...) et ne nécessite plus de dépendances externes comme playerctl ou l'API Spotify.
>
> 👉 [github.com/Collectif-Pixel/orpheus](https://github.com/Collectif-Pixel/orpheus)
>
> Installation :
> ```bash
> brew install collectif-pixel/tap/orpheus
> orpheus start
> ```
